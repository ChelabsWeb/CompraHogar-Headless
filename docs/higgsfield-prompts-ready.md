# Prompts listos para Higgsfield — copy-paste directo

Checklist práctico: cada bloque tiene el prompt completo con el sufijo de marca
ya integrado. Abrilo, copy, pegá en Higgsfield, generá, descargá.

---

## Cómo usarlo en Higgsfield

1. Entrá a [higgsfield.ai](https://higgsfield.ai).
2. Abrí el modelo **Soul** (cinematográfico, el que mejor rinde para fotos
   realistas — no uses Steel ni Draw para estos assets).
3. Pegá el prompt en el campo **Prompt**.
4. Configurá el **aspect ratio** que indica cada asset (`16:9`, `4:3`, `4:5`, `1:1`).
5. Dejá los **seeds random** la primera vez, regenerá si no te convence.
6. Descargá en **máxima resolución** disponible (no el preview).
7. Antes de subir a `/public/`, pasalo por [TinyPNG](https://tinypng.com) para
   comprimir — sitios se caen con imágenes de 5MB.

**Tip**: si Higgsfield te pide negative prompt, usá este genérico en todos:
`blurry, low quality, cartoon, illustration, CGI, 3D render, watermark, text overlay, people faces, logos`
